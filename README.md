# Ocean Legacy Challenge App

Streamlit app for the Ocean Legacy Challenge.

## Run locally

```bash
pip install -r requirements.txt
streamlit run Home.py
```

## Structure

- Home.py
- utils.py
- pages/1_Dashboard.py
- pages/2_Day1_Awareness.py
- pages/3_Day2_Strategies.py
- pages/4_Day3_Maintenance.py

## Goal

Help university students reduce fast-fashion consumption through awareness,
sustainable actions, and a long-term legacy plan.
